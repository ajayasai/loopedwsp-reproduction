# Ancestral plumage on a tree

Given the feather patterns at the tips of a supplied tree, which patterns could each ancestor have had if the whole tree accumulated as few pattern changes as possible? This example treats *plain*, *barred* and *spotted* as three distinct states of one hypothetical character. Every edge on which the pattern changes costs one. [Fitch’s original description of minimum-change ancestral states](https://academic.oup.com/sysbio/article-abstract/20/4/406/1673276)

## Try the example

From the repository root, run the four-tip example.

```sh
python frontier/experiment.py predict plumage --input frontier/examples/plumage.json
```

| Node | Children | Globally optimal patterns |
| --- | --- | --- |
| 4 | 0 (plain), 1 (barred) | plain |
| 5 | 2 (plain), 3 (plain) | plain |
| 6 (root) | 4, 5 | plain |

The first pair of tips alone gives node 4 two equally good choices. Connecting the other pair resolves it. A plain ancestor at node 4 allows the entire tree to be explained by one change, along the branch to the barred tip.

## Supply a tree

Give `tips` as a list of 2–32 patterns in lowercase. For *L* tips, their identifiers are 0 through *L−1*. Give exactly *L−1* pairs of children in `joins`. The first pair defines node *L*, the next defines node *L+1*, and the final pair defines the root. Each child must already exist and have exactly one parent. The JSON result lists each internal node and every state attained there in at least one globally optimal reconstruction.

The sets describe individual ancestors across optimal reconstructions. Choosing a state independently from each list can combine choices from incompatible reconstructions. All trees and plumage observations in the benchmark are synthetic. The input supplies the topology, and the model assumes equal transition costs in both directions.

## How the weights work

Two attention heads read the left and right children by node identifier. A repeated block accumulates the cost below each node for all three candidate patterns. A return pass follows the same edges in reverse, adding evidence from the parent side and the sibling subtree. A ReLU readout marks every state tied for the smallest whole-tree cost. The five stored FP32 coefficients control address sharpness, the unit change cost and the three output bits. Fixed tree routing, repeated operations and temporary cost vectors also contribute to the computation.

The benchmark includes ladder-shaped trees, nearly balanced trees and random joins. It mixes independently assigned tip states with observations generated by passing states down the tree with occasional changes. The scored targets are the equally parsimonious ancestral states for the observed tips. The separate scalar reference traces all tied choices from the root to the tips.
