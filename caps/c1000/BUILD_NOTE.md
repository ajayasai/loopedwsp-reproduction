# 965-weight raw-text maze transformer

The two-layer recurrent block has width ten. Each layer contains one softmax head with four query/key features and a four-unit ReLU MLP. The two heads use four and one value features respectively. All 965 stored scalar entries count toward the 1,000-weight cap. Of these, 112 are nonzero.

Each input character occupies one token, including each of the 29 newlines. Its embeddings encode its character, text line, text column and squared distance to the fixed text position `(15,15)`. Generic positional digit fields produce these attributes for any text. The weights use five bits per coordinate and nine bits for the squared distance, covering every position in a 30×30 maze including its newline separators.

The residual contains the row, column, squared norm, tile code, path mark, three offsets to the selected parent, one scratch value and a scalar equal to one plus `2^-28` times the visited bit. The goal starts visited. The start is initially marked. The first attention score favors the nearest visited neighbor just enough to beat the cell itself on a first visit. Directional score increments resolve ties in down, left, right, up order. Walls and newline tokens cannot be visited. Once a cell has been reached the self key wins. The head sends the winner's position and the MLP subtracts the cell's own position, leaving a permanent offset to the first selected neighbor. A ReLU caps the visited bit at one.

The second attention compares the query position with the saved parent position of every sender. It prefers marked senders at the same address and uses a smaller, unique position bias to break ties. Its value is twice the parent's flattened text address plus the sender's mark. A three-ReLU integer equality test latches the mark precisely when a marked sender points to the querying cell. The remaining ReLU clears the scratch value. The readout preserves the original tile or newline and changes a marked space to `o`.

The sender-position tie increment is `1/8192`. Across this input size the perturbation from encoding visited and constant in the same channel is below `2251 / 2^28`. Scaling by `2^24` leaves more than 1,900 between the closest competing FP64 logits. Losing probabilities underflow exactly to zero. Stronger geometry and mark choices have larger gaps.

The declared loop budget is twice the token count, or 1,858 rounds for the 929-character benchmark input. The wave reaches the start after the route length in rounds, then the mark advances one edge per round along its saved parents. Every reachable cell has settled after at most 899 rounds, and the route has reached the goal by round 1,798. The dense attention matrix multiplications account for `26 × 929² × 1858` FLOPs, about 41.7 billion. Projections, softmax and MLP work add to that term. The complete runner-counted budget is recorded in the shared evaluation output.

The dense handmade checker exactly reproduced all 300 independently generated raw grids of side two through eight, including their newlines and tie choices. Every FP64 attention row tested had exactly one nonzero. The shared evaluator records the official DEV and held-out results separately.
