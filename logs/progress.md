# Maze experiment log

## 24 November 2026

1. Audited the official training CSV before constructing the solver. All 1,000 labels represent shortest paths. All 1,000 grids admit several shortest paths. The only priority order that matched every label was down, left, right, up when progressing from start to goal. [Audit](../results/maze/uniqueness.json)
2. Authored the analytic 24-dimensional two-layer tied block. The local dense reference passed three handmade test groups. Wrote the 30×30 tensor archive and verified its values against the builder. [Model details](../src/maze/EXPLAIN.md)
3. DEV evaluation 1 of 20 allowed. Private Kaggle DEV version 1 ran on a Tesla T4 with FP64. Synthetic logits matched dense NumPy at seven checkpoints. The model solved 1,000/1,000 DEV grids at logical checkpoints 1,800, 3,600 and 7,200. All 16 batches reached exact one-block full-state equality within 304 executed blocks. Inference took 28.43 seconds. [DEV result](../results/maze/dev.json) · [Kaggle receipt](../kaggle/runs/dev/v1/submission.json)
4. Reviewed the generic forward, the first-arrival pointer rule, numerical precision, hash and DEV gates. Froze the model and source ahead of the single TEST submission. [Freeze record](../results/maze/freeze.json)
5. TEST evaluation 1 of 1. Private Kaggle TEST version 1 ran the same source bundle and tensor hash on a Tesla T4. The backend comparison passed. All 1,000 held-out grids matched at each logical checkpoint. All 16 batches reached an exact full-state fixed point within 320 evaluated blocks, and inference took 27.45 seconds. Only aggregate evidence was downloaded from the TEST run. [TEST result](../results/maze/test.json) · [Kaggle receipt](../kaggle/runs/test/v1/submission.json)
6. For the larger-maze study, locked 50 fresh 60×60 grids and 40 fresh 100×100 grids from the released generator, with seeds 2026112460 and 2026112500 respectively. All 90 sampled endpoints were reachable. A second shortest-path implementation checked every reference grid before inference. The model loads the prior archive directly and extends only the two analytic coordinate tables. The private offline Kaggle scale job received both fixed corpora in one submission. [Corpus hashes](../scale/corpus-lock.json) · [Scaling receipt](../kaggle/runs/scale/v1/submission.json)
7. Kaggle scale version 1 completed on a Tesla T4. At 60×60 it matched 50/50 reference grids in 13.719585 seconds. At 100×100 it matched 40/40 in 73.977710 seconds. The larger-grid results carry the frozen tensor hash and the pre-submission corpus hashes. [60×60 results](../results/maze/scale-60.json) · [100×100 results](../results/maze/scale-100.json)
8. Constructed five new capped raw-text models. The 5k–40k builds each passed a CPU check on eight DEV grids on their first official DEV call. For the 1k model, an unfinished first CPU DEV call was superseded after a synthetic check prompted a larger numerical margin. The revised model passed the eight-grid CPU DEV check on its second call. Each frozen model passed GPU parity before one official TEST evaluation. All five achieved 1,000 exact grids out of 1,000 on private Tesla T4 runs. [Counts and model hashes](../results/maze/caps/summary.json) · [Experiment details](../caps/README.md)
9. Froze fresh graph-distance, parity and reasoning-chain transformers after CPU development checks. Locked 25 size-specific evaluation sets and ran them on a private offline Kaggle Tesla T4 in FP64. The graph model solved 576/576, parity 704/704, and chains 512/512. All 1,184 out-of-range cases passed. The answers agreed at 1×, 2× and 4× the base loop budget. Verified the server-side source, weights and corpus fingerprints against the local freeze and checked each measured size. [Results by size](../results/lengths/report.md) · [Kaggle verification](../kaggle/runs/length-generalization/v1/verification.json)
10. Constructed two fresh analytic sequential-puzzle models. Froze the 11,062-parameter Hanoi model after testing 1–6 disks and the 13,233-parameter Checker Jumping model after testing 1–3 per side. All nine literal development decodes agreed with the batched decoder, including on the private Tesla T4. The frozen single GPU sweep produced legal optimal solutions at all 60 sizes, including 51 held-out sizes. It emitted 2,097,130 Hanoi moves in 1.755429 seconds and 23,780 checker moves in 0.381444 seconds across all sizes. Each sequence ended with EOS and remained identical at 2, 4 and 8 block passes. A second board-state implementation replayed every downloaded move. [Per-size report](../results/puzzles/report.md) · [Second replay](../results/puzzles/replay-audit.json) · [Kaggle verification](../kaggle/runs/sequential-puzzles/v1/verification.json)
11. Extended the study to inventory shortfalls, one-resource booking conflicts and sensor alarms. Froze fresh weights and 960 synthetic test records before submitting private T4 version 1. Each model scored 320/320 exact records and 15,872/15,872 flags. All 576 records longer than development scored exactly. NumPy and Kaggle FP64 predictions matched byte for byte at every size, and separate local verifiers checked all 47,616 labels. [Per-size results](../results/applications/report.md) · [Verification](../results/applications/verification.json)
12. Published the frozen loop comparison protocol at 04111d2 before submitting private Kaggle v1. A Tesla T4 ran 315 settings over the same 960 released records and 480 paired challenge records. With the original weights at FP32 and FP64, one pass solved 155 released records, four solved 381 and full depth solved all 960. The non-recurrent global baselines solved all 1,440 records in FP16, FP32 and FP64. All 450 downloaded prediction arrays were regraded, and they also matched a separate CPU inference run. The report includes native FP16 numerical failures, raw final-logit scores, per-size synchronized timings and parameter-budget comparisons.
